# orange-story

The orange.io website, built as one continuous scroll story: four chapters (The Model, The Work, The Terms, Questions) and a finale, told through painted scenes of an orange tree, its keepers and its harvest.

This repository is being built phase by phase with Claude Code. The full README (screenshots, setup, structure, editing guides) is generated in the final phase.
